## <picture><img src = "https://github.com/7oSkaaa/7oSkaaa/blob/main/Images/about_me.gif?raw=true" width = 50px></picture> About me
 
I started out in network operations (NOC) and since 2024 I've been working in **QA, automation, and application security**. I design and automate functional, regression, and security tests for REST and SOAP APIs, and I've contributed to consolidating an **SSDLC**: security checklists, code and design reviews, automated tests, and security requirements definition.
 
This profile brings together personal projects focused on **Security Testing, QA Automation, and Application Security** — all built on my own time, with no data or code from any employer.
 
- 🔐 Currently working on: an API security checklist based on OWASP, plus practicing on HackTheBox / TryHackMe
- 🎯 Open to opportunities in **QA Automation**, **Security Testing**, and **SSDLC / AppSec**
- 💬 Ask me about: API testing, automation with Python/Selenium, OWASP Top 10
